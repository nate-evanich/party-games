How to play

1
Install

Clone the repo and run npm install. Node 20+ is the only prerequisite — no database, no Docker, no external services.

2
Run

Start the server with npm run dev and open http://localhost:3000. Pick any game to create a room instantly.

3
Share the room code

Send the short room code (or link) to friends. They join from any browser — on the same network or anywhere on the internet if you deploy it. No accounts, no installs for players.

An open-source real-time multiplayer games starter — MIT licensed, built with Next.js + Socket.IO.
